# Melt3D monochrome logo study

SVG vector assets reproduced from the owner-supplied logo concept (2026-10-17). All artwork, including wordmarks, uses path outlines instead of raster images or external fonts.

- `melt3d-mark.svg`: standalone flowing M symbol (transparent background).
- `melt3d-icon.svg`: white M in a black rounded-square icon.
- `melt3d-logo.svg`: app icon with the Melt 3D wordmark beneath.
- `melt3d-reference-layout.svg`: original two-part presentation, including the study label LOOP.

These are design assets only. They do **not** silently replace the existing application binary/platform icons or rename any code symbols. Review at small icon sizes before wiring them into builds.
