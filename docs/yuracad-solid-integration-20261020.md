# Melt 3D に組み込まれた SolidCraft

Melt 3D には SolidCraft v0.20.0 の通常の作業画面を組み込んでいます。独自の簡易CAD画面に置き換えず、SolidCraft の標準のツールバー、パネル、コマンド、設定、テーマを使います。表示言語は日本語です。Melt に戻るための細いバーだけは、SolidCraft の画面の外側に Melt が追加します。

## 開く・戻る

Melt 3D 上部の **SolidCraft** ボタン、または検索（F）で `Solid`、`SolidCraft`、`精密`、`ソリッド` を選ぶと開きます。Melt 側でスケッチや立体の操作中は、先に確定するか取り消してください。SolidCraft 側でスケッチやコマンド、ダイアログの操作中は Melt に戻れません。

SolidCraft 画面の上にある **Melt 3D に戻る** は、SolidCraft の通常UIとは別のホスト側の操作です。確定した立体があれば、戻る操作で自動的に Melt に受け渡します。SolidCraft の画面を同じアプリ内で開き直すと、開いていた設計を続けられます。

## 形の受け渡し

SolidCraft の立体を STL に書き出して一時ファイル経由で読み込み、Melt のメッシュ形状に変換します。Z上向き、mm、元の位置と大きさを使い、床置きや中央配置はしません。Melt にすでにある形は残ります。取り込みが完了した形は新しい Melt グループに入り、メルトなど通常の形状操作を使えます。

同じメッシュを連続して受け渡して重複するのを避けます。取り込み中は画面の切り替えを止めます。書き出し、読み込み、変換の失敗やキャンセルでは、SolidCraft 側の設計を保持し、再試行できます。

受け渡されるものはメッシュを距離ボリュームにした近似形状です。小さな穴、薄い壁、細かな面は変換解像度の影響を受けます。SolidCraft の寸法やフィーチャー履歴を必要とする場合は、SolidCraft 側から STEP などの形式で書き出してください。

## ファイルと復旧

SolidCraft の設計と Melt のシーンは別の文書です。

- SolidCraft 側で `.solidcraft` を保存すると、スケッチ、寸法、拘束、フィーチャー履歴を含む設計を保存します。
- Melt 側で `.meltcad` を保存すると、受け渡したメッシュ形状を含む Melt シーンを保存します。SolidCraft の編集履歴やリンク元ファイルは含みません。
- SolidCraft 側であとから形を直して Melt に戻すと、その形を新たに取り込みます。Melt 上でメッシュを編集して SolidCraft の履歴に戻すことはできません。

SolidCraft の自動保存・復旧機能を組み込み画面でも使います。通常のアプリ終了では、SolidCraft の未保存設計を確認した後、必要なら Melt シーンの未保存確認を行います。Melt に戻るときにも SolidCraft の自動保存を試みます。

`--control` からは `{"cmd":"ui.precise","on":true}` で開き、`on:false` で Melt に戻ります。画面のない `--run` では使えません。

## 移植元と確認状況

SolidCraft v0.20.0 の移植元はリリースコミット [`a06bdf5cfc5b108126d774ae6f684c4c2b3764fc`](https://github.com/bherbruck/solidcraft/commit/a06bdf5cfc5b108126d774ae6f684c4c2b3764fc) です。このコミットは v0.20.0 のリリースコミットです。取り込みは、その後の GitHub main `edf57cec293dcea301201f1d5173b33e16351466` まで進めています。UI・エンジン・カーネルはこの main のソースをそのまま使用します。Melt のホストサービスと `geom::melt` の追加は別に保持します。

この更新後のローカル検証はまだ行っていません。旧版向けの画面確認結果やテスト件数は、現在の移植状態の検証結果として扱いません。
