# Melt 3D の SolidCraft 統合（2026-10-20）

Melt 3D の中で、寸法・スケッチ・履歴を使う SolidCraft の作業画面を開く。精密な形を作ってから Melt の画面へ戻り、ほかの形と溶かす・削る・色を付ける操作へ続けられる。

## 開く場所と基本操作

上の「SolidCraft」から開く。検索パレット（F）では `Solid`、`SolidCraft`、`精密`、`ソリッド` で同じ入口を探せる。作業中の Melt のスケッチや立体プレビューは、確定または取消をしてから切り替える。

SolidCraft の上部には日本語で作業の流れを表示する。スケッチを描く、押し出す、形を仕上げる順に進め、必要な寸法を入力する。SolidCraft の既存のスケッチ・拘束・フィーチャー・STEP 書き出しを使う。

上部の選択フィルター・表示パネル切り替えの6ボタン列は表示しない。スケッチの道具、視点操作、設定パネルは引き続き使える。

「Melt 3D に戻る」で作った立体を自動で受け渡す。立体がない場合は Melt の画面へ戻る。SolidCraft の作業状態は同じアプリを開いている間は保持され、再び入ると編集を続けられる。

## 形の受け渡し

受け渡した形は、SolidCraft の大きさ（mm）と位置を保って Melt 側へ追加する。床へ移動したり、画面の中心へ置き直したりしない。Melt 側に先に置いていた形は保持する。

取り込み後は Melt の設定を表示し、新しいグループのメルトを有効にする。全体のメルト量を変えると、周囲の形との溶け合いを調整できる。グループ側でメルトを切れば、ほかの形との境界を保てる。

同じ立体を変更せずに戻ったときは重複して追加しない。受け渡しを完了した形だけを送信済みと扱う。変換・読み込みが失敗または取り消された場合は、SolidCraft の作業を保ち、同じ形でも再試行できる。失敗の理由は画面に表示する。

Melt で使う形は、精密な立体をメッシュへ書き出し、メルト用の距離データへ変換した近似となる。薄い壁、小さい穴、細かい角は変換の解像度による差が出る。精密な寸法や面の情報が必要な書き出しは SolidCraft 側の STEP を使う。

## 保存と編集範囲

SolidCraft の精密な設計と Melt の作品は別の文書として扱う。寸法、拘束、フィーチャー履歴を後で編集するには、SolidCraft 側で `.solidcraft` を保存する。`.meltcad` には受け取った Melt の形が保存される。

精密な文書にも30秒間隔の自動復旧を設定し、Melt に戻るときと終了時にも未保存の設計を保管する。再起動後に SolidCraft を開くと復旧候補を確認できる。通常の終了では、画面のどちらのモードから閉じても未保存の精密文書を確認し、その後に Melt の未保存確認へ進む。

外部操作では `--control` の `{"cmd":"ui.precise","on":true}` で開き、`on:false` で同じ自動取り込みを通って戻る。編集中の切り替えは拒否する。画面のない `--run` からは使わない。

Melt に移したメッシュの編集は、SolidCraft の履歴へ自動で戻らない。SolidCraft 側で形を変えて再び戻ると、新しい受け渡しになる。Melt の形から精密な履歴を逆算する機能や、二つの文書を一つのファイルへまとめる機能は含まない。

## 確認する操作

- 上の入口と検索パレットから同じ SolidCraft 画面を開ける。
- 未確定の Melt 操作を保護し、確定・取消のあとで切り替えられる。
- 日本語の案内からスケッチと立体の編集を進められる。
- 原点から離れた立体を戻しても、大きさと位置が変わらない。
- 受け渡しの成功後は同じ形が重複せず、失敗・取消のあとは同じ形を再試行できる。
- SolidCraft の作業を続ける場合と、Melt へ戻る場合の保存対象が分かる。

確認はアプリの既存テストとヘッドレスの UI プレビューで行い、画面画像はソース管理へ追加せずレビュー資料として扱う。
