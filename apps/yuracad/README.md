# YURACAD（ユラキャド）

YURACAD は、やわらかい形を かんたんに作れる 3D モデリングアプリです。Womp3D のように、形を **足したり**、**くり抜いたり** して立体を作ります。

- 形どうしが とけて くっつく（メルト）
- 小さい形で くり抜く（削る）
- 絵をかいて、ぐーっと押し出す（スケッチ → 押し出し）
- 色や つやを決める（ざいしつ）
- STL ファイルに書き出して、3D プリンターで印刷する

## はじめかた

Rust が入っていれば、このリポジトリのフォルダで次のコマンドを打つと起動します。

```
cargo run --release -p yuracad
```

作品ファイル（.yura）の名前を後ろにつけると、その作品を開いて起動します。

```
cargo run --release -p yuracad -- 作品.yura
```

起動直後は、球が 1 つ置かれています。左の「形を足す」から形を選ぶと、えらんでいる形のとなりに新しい形が出てきます。

## 3D 画面の操作（マウス）

| 操作 | 何をする |
|---|---|
| 右ドラッグ | 画面を動かす |
| 中ドラッグ | 見る角度を回す（Shift で画面を動かす、Ctrl で近づく・遠ざかる） |
| Alt + 左ドラッグ | 見る角度を回す |
| ホイール | 近づく・遠ざかる |
| 左クリック | 形をえらぶ（何もないところならえらびを外す） |
| Shift + 左クリック | えらんでいる形をもう一度クリックすると、その形のグループをえらぶ |
| 右クリック | そこの形をえらんで、メニューを出す（複製、＋⇄−、ここを見る、名前を変える、削除） |
| 何もえらんでいない時にダブルクリック | 全体を見る |

えらんだ形には、動かす・回す・大きさを変えるための目印（矢印、輪、四角）が出ます。ドラッグして使います。Ctrl を押しながら動かすと 1mm ずつ、回すと 15 度ずつ動きます。

画面の右上にある X・Y・Z の丸をクリックすると、その軸の方向から見ます。薄い丸は反対側からの見方です。

| Ctrl+O | 開く |
| Ctrl+E | STL に書き出す |

## メルト（とけあい）

右のいちばん上がメルトです。

- プリセット: かたい、やわらか、ぷりぷり、チーズ、はちみつ、とろとろ。押すと、下の設定がまとめて変わります。
- とけかた（モード）: なめらか（ふつうにやさしくとける）、まるく（ふっくら丸くとける）、どろっと（長く、のびるようにとける）
- とけぐあい（0〜4）: 全部の形のとけあいを、いっぺんに強くしたり弱くしたりします。0 にすると、とけあわずに かどが立ったままになります。
- たれ（0〜40）: 下にたれるように溶けます。0 でたれません。
- たれの細かさ（0.3〜4）: たれの間かくです。大きくすると、たれが細かく並びます。
- 絵（プレビュー）で、今の設定の見た目を確認できます。

形ごとの「とけあい」（0〜60mm）は、形をえらぶと右の「えらんだもの」の中に出ます。その形がまわりとどのくらい溶けてくっつくかを決めます。グループには「前のグループととけあう」（0〜60mm）があります。

## グループ

- 形は グループ にまとめられます。左の「グループを作る」で作れます（最大 24 グループ）。
- レイヤーのグループの行をえらぶと、グループごと動かす・回す・大きさを変えられます。
- ＋（足す）と −（削る）のマークを押すと切りかわります。足すはくっつき、削るはくり抜きます。
- えらんだ形やグループの「↑ ↓」ボタンで順番を入れかえられます。形は「グループを移す」で、ほかのグループへ移せます。
- 名前は、レイヤーの名前をダブルクリックするか、右クリックの「名前を変える」で変えられます。

## 形の設定と ざいしつ

- えらんだものの欄で、名前・足す／削る・位置（mm）・回転（度）・大きさ（×）を決めます。大きさの数字は形によって違います（球は半径、箱は幅・奥行・高さ など）。
- ざいしつの丸いボタン 12 種（クレイ、ストロベリー、ミント、スカイ、ラベンダー、レモン、ゴールド、カッパー、クローム、パール、ミルク、すみ）を押すと、えらんでいる形の色・つや・金属感がまとめて変わります。
- 下の「いろ」「つや」「金属」で、自分で細かく決められます。

## スケッチ（押し出し）

1. 左で「押し出し」を足します。
2. えらんだものの欄に出る「スケッチ（輪かく）」で、輪かくを作ります。点をドラッグすると角が動き、線をクリックすると角が増えます。点をダブルクリック（または右クリック）すると角が消えます（3 つより少なくはできません）。四角・三角・六角・星・十字 のボタンで、まるごと入れかえられます。
3. 「高さ」で、上に押し出す長さを決めます。

## もどす・保存・書き出し

- Ctrl+Z でもどし、Ctrl+Shift+Z か Ctrl+Y でやりなおします。マウスを離すと、そこまでが 1 回分です。200 回までもどせます。作品を開くと、もどす履歴は消えます。
- Ctrl+S: いま開いている作品に保存します。まだ名前がない時は、保存先と名前を聞かれます（初期名は「作品.yura」）。名前の後ろの * は、保存していない変更があるしるしです。
- Ctrl+O: 作品を開きます（.yura か .json）。
- .yura は ふつうの JSON（文字だけのファイル）です。メモ帳などで中身を見られます。範囲をこえた数字は、読み込み時に安全な範囲に直されます。
- STL: 右上の「STLで書き出す」ボタン、または Ctrl+E。右上の「書き出し」の欄で きれいさ を選べます（ふつう＝軽い、きれい＝最初の設定、とてもきれい＝重い）。形式はバイナリの STL で、単位は mm です。きれいさの設定は 作品ファイルには保存されません。

## 上限

- 形: 64 個まで
- グループ: 24 個まで
- スケッチの角: 16 個まで（最低 3 個）
- もどす: 200 回まで
