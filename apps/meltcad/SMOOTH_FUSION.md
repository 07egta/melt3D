# MeltCAD · Smooth Fusion（なめらか合体）

## 操作方法

「左ツール列 → 合体」または「メルト → Smooth Fusion」から、3〜8個の基本形状を使ったサンプルを追加します。モデルライブラリの最後の「Fusion」カテゴリにも同じ6種類があり、`F` 検索で `Smooth Fusion` / `Smooth Union` / `なめらか合体` がヒットします。

- **接合部の丸み（mm）**：選んだFusionグループ内の `Add` 子形状の既存 `Shape::blend` を更新します。0mmはハードBoolean Unionです。
- **融合範囲**：0は深く重なった形、1は離して軽く触れる形を目指します。子形状の重心を基準に位置だけを比率変更します。実際の接触状態は形状の寸法と編集済み位置に依存し、幾何学的な接触制約ではありません。
- **子形状を編集する**：シーン一覧から球・箱・円柱を選び、位置・回転・倍率・材質・個別ブレンドなどを変更できます。Fusionの調整はメッシュ化せず、編集後のパラメータをそのまま保持します。

**重要：** 現行の Smooth Union モードはシーン全体で共有される `scene.melt.mode` の設定です。Fusion挿入時には既存の `BlendMode::Smooth` を指定し、`amount=1`、`drip=0` に変更します。この変更は他のグループにも適用されます。ユーザーがその後シーン全体のメルトモードを変更した場合、Fusionグループのインスペクターに警告と復帰ボタンを表示します。

## 技術構成・精度

- **新規Boolean演算は実装しません。** 既存の `sdf::smin`、`Field::group`、GPU shader、`accel::group_info` および `gpu::pack_shape` を再利用します。
- プリセットは各3〜8個の `Kind` / `Shape` を普通の `Group` に収めたものです。GPUにも同じ個数のプリミティブとして転送され、SDFボリュームや三角形ベイクは作りません。
- グループの `fusion: Option<SmoothFusion>` は、丸みと接触距離のエディター値だけを保存します。`#[serde(default)]` により古いプロジェクトはこの項目なしでロードできます。
- スライダーによる変更は子形状数 N に対して O(N) の数値更新だけです。SDFの再計算・再描画は既存のシーン差分検出とキャッシュ、空間的な除外最適化が担当します。カメラ操作時に融合用の新規処理を走らせません。
- 「軽い接触」は正確な面同士の距離拘束ではありません。ユーザーが各形状の位置を変更した場合、接触感のスライダーは現在の重心を基準に再配置します。
