# MELTCAD（メルトキャド）

MELTCAD は、やわらかい形を かんたんに作れる 3D モデリングアプリです。Womp3D のように、形を **足したり**、**くり抜いたり** して立体を作ります。

- 形どうしが とけて くっつく（メルト）
- 小さい形で くり抜く（削る）
- 絵をかいて、ぐーっと押し出す（スケッチ → 押し出し）
- 色や つやを決める（ざいしつ）
- STL・3MF・OBJ・PLY・GLB に書き出して、3D プリンターで印刷したり ほかのソフトで使う

## はじめかた

Rust が入っていれば、このリポジトリのフォルダで次のコマンドを打つと起動します。

```
cargo run --release -p meltcad
```

作品ファイル（.meltcad。古い .yura も開けます）の名前を後ろにつけると、その作品を開いて起動します。

```
cargo run --release -p meltcad -- 作品.yura
```

起動直後は、球が 1 つ置かれています。上のまんなかの形のボタンを押すと、えらんでいる形のとなりに新しい形が出てきます。

## 画面のならび

- **上のバー**: ファイル、編集、元に戻す／やり直し、「さがす F」、まんなかに作品の名前、右に がしつ と 書き出し
- **左のドック**: 「シーン」（形の一覧）と「ライブラリ」（できあいの形）のタブ。シーンは、クリックでえらぶ・行のドラッグで順番やグループを入れかえ・目のマークで表示／非表示・＋−●のマークで 足す → 削る → ぬる → 重ねる
- **画面の左の縦ボタン**: 形（球・箱・円柱・ドーナツ・円すい・押し出し）、せん、「…」（ほかの形・CADの機能）、足す／削る／ぬる／重ねる、グループ
- **右のパネル**: タブで切りかえ。「形」（位置・回転・大きさ・とけあい）、「ざいしつ」、「メルト」、「ライト・背景」
- **下のまんなか**: 道具（選ぶ・ぜんぶ・動かす・回す・大きさ）、遠近／平行、全体、操作のしかた（?）
- **見た目**: 落ち着いたグレーのフラットなテーマに、緑のアクセント。アイコンは細い線の絵。えらんでいるものは緑になります

## 3D 画面の操作（マウス）

| 操作 | 何をする |
|---|---|
| 右ドラッグ | 画面を動かす（パン） |
| 中ドラッグ | 見る角度を回す（Shift で画面を動かす、Ctrl で近づく・遠ざかる） |
| 左ドラッグ（何もない所から） | 見る角度を回す（Shift で画面を動かす） |
| Alt + 左ドラッグ | 見る角度を回す |
| ホイール | マウスのある所へ近づく・遠ざかる |
| 左クリック | 形をえらぶ（何もないところならえらびを外す） |
| Shift + 左クリック | えらんでいる形をもう一度クリックすると、その形のグループをえらぶ |
| ダブルクリック | その形を見る（何もない所なら全体） |
| 右クリック | そこの形をえらんで、メニューを出す（複製、＋⇄−、ここを見る、名前を変える、削除） |

マウスを形の上に乗せると、その形がほんのり光ります。Shift+F や Home、1・3・7 で見る向きを変えると、画面がなめらかに動きます。

### gizmo（動かす・回す・大きさの目印）

標準の「ぜんぶ」では、Womp3D と同じように 1 つの目印で全部できます。

| 目印 | 何をする |
|---|---|
| 色つきの矢印 | その向き（X 赤・Y 緑・Z 青）にだけ動かす |
| 矢印のあいだの四角 | その面の上で、自由に動かす（2 つの軸いっぺんに） |
| 曲がった矢印 | その軸のまわりに回す |
| 真ん中の丸 | 大きさを変える（中心は動かない）。Shift を押しながらだと画面の面の上を動かす |
| 箱の角の四角 | 角をひっぱって、軸ごとにばらばらに大きさを変える |

Ctrl を押しながらドラッグすると、動かすのは 1mm ずつ、回すのは 15 度ずつ、大きさは 0.05 ずつです。「動かす」「回す」「大きさ」の道具は、その種類の目印だけを出します。

画面の右上にある X・Y・Z の丸をクリックすると、その軸の方向から見ます。薄い丸は反対側からの見方です。

## 足す・削る・ぬる・重ねる

- **足す（＋）**: 形をくっつけます。
- **削る（−）**: くり抜きます。
- **重ねる（◐）**: それまでの形と、かさなっている所だけをのこします（交差）。上のボタン・右の「形」タブ・シーンの一覧のマークから選べます。グループにも使えます。
- **ぬる（●）**: 形は変えずに、その形の中にある表面の色・ざいしつだけをぬります（Womp3D の Stain と同じ）。

## メルト（とけあい）

右の「メルト」タブです。

- プリセット: かたい、やわらか、ぷりぷり、チーズ、はちみつ、とろとろ。押すと、下の設定がまとめて変わります。
- とけかた（モード）: なめらか（ふつうにやさしくとける）、まるく（ふっくら丸くとける）、どろっと（長く、のびるようにとける）
- とけぐあい（0〜4）: 全部の形のとけあいを、いっぺんに強くしたり弱くしたりします。0 にすると、とけあわずに かどが立ったままになります。
- たれ（0〜40）: 下にたれるように溶けます。0 でたれません。
- たれの細かさ（0.3〜4）: たれの間かくです。大きくすると、たれが細かく並びます。

形ごとの「とけあい」（0〜80mm）は「形」タブの中にあります。グループには「前の組ととけあう」（0〜80mm）があります。

## グループ

- 形は グループ にまとめられます。上の「グループを作る」で作れます（最大 96 グループ）。
- シーンのグループの行をえらぶと、グループごと動かす・回す・大きさを変えられます。
- 行のドラッグで、形の順番を入れかえたり、ほかのグループへ移したりできます。
- 名前は、シーンの名前をダブルクリックするか、右クリックの「名前を変える」で変えられます。

## パターン・ミラー・インスタンス

グループには「パターン」をつけられます。**形のワクを使わずに**、グループぜんぶのコピーをたくさん出します（右の「形」タブでグループをえらぶと、「パターン」のらんが出ます）。コピーは 画面・書き出し・クリックでえらぶ（えらぶと元のグループがえらばれます）・プリントチェック すべてに入ります。コピーどうしは、グループの「前の組ととけあう」で とけあいます。

| 種類 | どうなる |
|---|---|
| ミラー | X・Y・Z の面で左右（前後・上下）にうつします。面は「原点」か「グループの中心」を通ります。**ミラー X / Y / Z** のボタン 1 つで、片がわだけ作れば反対がわが同時にできます |
| 矩形状 | X・Y・Z に、こすうと間かく（mm）でならべます。1 こ目は今の場所です |
| 円形状 | 軸（X・Y・Z）と中心、こすうと角度（360° でぐるっと）。「コピーもいっしょに回す」を切ると、向きはそのままです |
| パス上 | 「たどる線」（線・スイープ・押し出しなどの形）の上に、グループの中心をならべます。「ぴったり」は はしからはしまで同じ間かく、「きょり」は決めた長さごと。「線のむきにそろえる」で向きも合わせます |
| ジオメトリ | ほかの形（またはグループ）の点ごとに 1 こずつおきます。線・スイープ・押し出しは ふし・かど、箱は 8 つの角、ほかの形は中心です |

「いまの数」が出ます。シーンぜんぶで 256 こをこえると、のこりは作られず、赤い字で知らせます。

**インスタンス（リンクコピー）**: 「編集 → インスタンスを作る」で、えらんだグループの「つながったコピー」ができます。形は元のグループのものをそのまま使い、位置・回転・大きさだけ自分のものを持ちます（画面の矢印・輪・真ん中でも動かせます）。**元を直すと、すべてのコピーが同じに変わります**。「リンクをはずす」で、ふつうのグループにもどせます。コピーのコピーは、もとのグループのコピーになります。

「編集 → パターン」、検索（F）の「パターン」「ミラー」「インスタンス」からも使えます。ファイルには、パターンは数字だけで書かれます（古いファイルはそのまま開けます）。

## ざいしつ

右の「ざいしつ」タブです。ボールの絵（プレビュー）を押すと、えらんでいる形のざいしつが変わります。「グループ全部に」にチェックを入れると、グループのぜんぶの形が同じざいしつになります。

- カテゴリ: ベーシック、金ぞく、ガラス、ひかる、ふしぎ、★マイ（自分で保存したもの）。全部で 50 種ちかく。
- 「★ ほぞん」で、いまのざいしつを「★マイ」にためられます（作品ファイルといっしょに保存されます。右クリックで消す）。
- くわしく: いろ、つや、金属、**とうめい**（ガラス。光が曲がって後ろが透けて見えます）、**ひかる**（ランプ・ネオン。まわりがぼんやり光ります）、**にじいろ**（シャボン玉・タマムシ）、**コート**（車のペンキ・キャンディのようなピカピカの層）、**すけ感**（ワックス・ゼリー・こおりのように光がしみこむ）。

- **グラデーション**: スイッチを入れると、「いろ」から「2つ目の色」へ、形のはしからはしまでなめらかに変わります。向きは 上下・左右・前後、「反転」で色の向きをぎゃくに、「形にそう」を入れると形を回しても色がついてきます（切ると、いつも世界の上下左右）。「とけぐあい」で くっきり ⇄ ゆっくり、「つよさ」で 2つ目の色がどのくらい出るか、「ここから／ここまで」で色がかわる場所をえらびます。「ふしぎ」にサンセット・うみ・ラムネ・いちごミルク・オーロラ・もりのあさ があります。「ぬる」の色は、グラデーションの上にそのまま かさなります。

## 丸み・面取り

右の「形」タブの「丸み」で、角やふちを丸くできます（球・カプセル・ドーナツ・カーブは もともと丸いので出ません）。箱・円柱・円すい・押し出し・かく柱・ピラミッド・くさび・星・パイプ・八面体・四面体・半球・回転体・ロフト・スイープ で使えます。大きすぎる値は、形がこわれない所でとまります。すぐ下の「丸 / 面取り」で、丸くする（フィレット）か、ななめに平らに切り落とす（面取り・チャンファー）かをえらべます。面取りは、丸みの数字ぶんだけ、角の両がわから 45 度に切ります（円すい・ピラミッドの先、八面体・四面体は ふちだけ）。0 のときは、これまでと同じ形です。

## ライト・背景

右の「ライト・背景」タブです。

- 雰囲気: スタジオ、ひるま、ゆうやけ、よる、キャンディ、しろ。ライトと背景と空がまとめて変わります。
- 背景の色、グリッドとゆか（影）のオン・オフ、明るさ（露出）、影のこさ、まわりの光。
- 空の色（金属やガラスに映ります）。
- ライトは 3 つまで。むき・たかさ・つよさ・色を決められます。ライト 1 だけが影を落とします。

## 線（カーブ）を作る・直す

Womp3D の線ツールと同じ感じで、玉（ふし）をつなげたなめらかなパイプを作ります。

- 上のバーの「せん」ボタンを押すと、クリックするたびに点（ふし）が増えて線がのびます。画面の中に何かあればその表面に、なければ地面に点が置かれます。マウスまで ゴム線が見えます。
- ダブルクリックか Enter で線を終えます（Esc でも終わります。もう一度 Esc でツールが切れます）。Backspace で最後の点を 1 つもどします。
- 「ふとさ」スライダーで、これから置く点の太さを決めます（はじめは 5mm）。
- 線をえらぶと、ふしが小さな丸で出ます（線の丸は、そのふしの太さと同じ大きさ）。

| 操作 | 何をする |
|---|---|
| ふしをクリック | そのふしをえらぶ（右の「ふし」の設定に出ます） |
| ふしをドラッグ | カメラに向いた面の上で動かす（Shift で地面と平行に、Ctrl で 1mm ずつ） |
| 端の「＋」の輪をドラッグ | 新しいふしを引きだして、線をのばす（クリックだけでも 1 つのびます） |
| ふしと ふしのあいだの「＋」 | クリックかドラッグで、そこにふしを足す |
| Alt + ふしをドラッグ | そのふしから線をのばす |
| えらんだふしの右はしの点 | ドラッグでそのふしの太さを変える |
| Delete / Backspace | えらんだふしを消す（2 つより少なくはできません） |
| [ ] | えらんだふしを 細く・太く |

右の「線のふし」には、なめらか（0 でカクカク）、輪にする、はしを平らに、ぜんたいの太さ、「ぜんぶのふしを同じ太さに」、ふしの一覧（太さ・消す）があります。「ふしをいじる」を切ると、画面のふしの丸は出ません（ふつうの gizmo だけ使えます）。スイープの道（パス）も同じふしの操作で直せます。
## パイプ（なぞって作る）

「せん」のとなりの「パイプ」ボタンを押して、画面の上を **ドラッグ** すると、なぞったとおりのなめらかなパイプができます（はなすと 1 本の「線」の形になります）。

- 形の上をなぞると、その表面にそってパイプがはりつきます（パイプの太さぶん、表面から浮いて乗ります）。何もない所は、地面（「なぞる面」で まえ・よこ にも変えられます）の上になぞれます。
- なぞった線は、手のふるえをならして、少ない「ふし」（24 こまで）に まとめてから、なめらかな曲線でつなぎます。クリックだけ・ほとんど動かさなかったときは、何も作りません。
- 出てくるカードで、**外半径**（はじめは 4mm）、**かべのあつさ**（はじめは 1.2mm。0 にすると中のつまった棒）、**とじた輪**、はし（**まる** / **すっぱり** = まっすぐ切って中の穴が見える）、色 を変えられます。いま作ったパイプは、カードを動かすとそのまま変わります。
- Alt + ドラッグ（または中ボタン）で画面を回せます。Esc でなぞる途中をやめる・もう一度でツールを切ります。
- パイプの「ふし」の丸をドラッグすると、ふつうの線と同じように直せます（ふしを足す・消す・ひとつずつ太さを変える）。「線のふし」の「なめらか」でカクカク〜なめらかを選べます。

線のふしは 48 こまで、1 本の線は なめらかにした 96 の点で測ります（GPU の線の置き場は、ぜんぶで 32768 の点です）。

## ほかの形

上のボタンの「ほかの形」から、10 この形が出せます。どれも まんなかが 原点で、Z が上です。大きさは「形」タブの数字で変えます。「まるめ」を上げると、かどが丸くなります（カプセル・半球は もともと丸いので 変わりません）。

| 形 | 大きさ | ほかの数字 |
|---|---|---|
| 三角柱 | 外半径・高さ | |
| 多角柱 | 外半径・高さ | 辺の数（3〜32） |
| 正八面体 | 半径（とがりまでの長さ） | |
| 正四面体 | 半径（とがりまでの長さ）。1 つのとがりが上 | |
| ピラミッド | 底の半径・高さ。底が下、てっぺんが上 | 辺の数（3〜16） |
| カプセル | 半径・長さ（両はしの球の中心どうしの長さ） | |
| 半球 | 半径。平らな面が下で、ドームが上 | |
| パイプ | 外半径・肉厚・高さ。肉厚が外半径いじょうだと 中の詰まった棒 | |
| くさび | 幅・奥行・高さ。左が高く、右へ下がるスロープ | |
| 星柱 | 外半径・高さ | とがり数（3〜16）、内側の比（0.1〜0.9） |

## スケッチ（平面に絵をかいて、立体にする）

左の縦ボタンの、えんぴつと多角形のボタンで「スケッチ」を始めます。

1. **面をえらぶ**: 床 / 正面 / 横 / えらんだ形の上（えらんでいる形のてっぺんの高さの水平な面）。えらぶと、カメラがその面を正面から見る向きにすべります。
2. **道具をえらぶ**: ポリゴン（クリックで角をうち、さいしょの点をクリック・Enter・ダブルクリックでとじる）、四角（ドラッグ、または2回クリック）、円（まん中から外へドラッグ。32 点）、スプライン（点を通るなめらかな輪かく。「なめらか / かくばる」で切りかえ）、線（ひらいた線。スイープの通り道）。
3. 点は **1mm きざみ** にそろいます。**Shift = 10mm、Ctrl（Mac は Command）= 0.1mm**。Backspace で1つもどる、Esc でやりなおし（何もかいていないときの Esc でスケッチを終える）。Alt+ドラッグ・中ボタン・右ボタンで、見る向きを動かせます。線が交差するような点は、うてません（かこみがとじないとき、とじた輪かくが交差しているときは、やさしいメッセージが出ます）。
4. 輪かくができると、カードに **押し出し / 回転体 / ロフト / スイープ** が出ます。
   - 押し出し: 高さ（スライダー＋数字）。「うらがわへ」で反対向きに。面の向きに合わせて、正しい向きにおかれます（正面は手前へ、横は右へ、床は上へ）。
   - 回転体: 「正面」か「横」でかいた輪かくを、たてのじく（画面の緑の線＝中心）のまわりに 360 度回します。じくより左に はみ出た分は切りとられます。
   - ロフト: 上の輪かくは「コピーを拡大・縮小」（倍率スライダー）か「もう1つかく」。
   - スイープ: 「線をかく」で通り道をかく（さっきかいた線をそのまま使うこともできます）。「ふとさ」は輪かくの倍率。
5. できた形は、えらんでいるグループに入ります（足す／削るは、左の縦ボタンの設定のとおり）。
6. **スケッチを編集**: 押し出し・回転体・ロフト・スイープをえらぶと、右の「形」タブに「スケッチを編集」のボタンが出ます。輪かくが画面の中の面の上に出て、点をドラッグで動かす、線をクリックで点をふやす、点をクリックして Delete で消す（3 つより少なくはできません）ことができます。やり直し（Ctrl+Z）も使えます。交差してしまう動かし方は、手をはなすと元にもどります。

## スケッチ（押し出し）の、右パネルでの編集

1. 上で「押し出し」を足します。
2. 「形」タブに出る「スケッチ（輪かく）」で、輪かくを作ります。点をドラッグすると角が動き、線をクリックすると角が増えます。点をダブルクリック（または右クリック）すると角が消えます（3 つより少なくはできません）。四角・三角・六角・星・十字 のボタンで、まるごと入れかえられます。
3. 「高さ」で、上に押し出す長さを決めます。

## CAD の機能（回転体・ロフト・スイープ・シェル）

上の「CADの機能」から足せます。断面は「形」タブのスケッチで かきます。

- **回転体**: 断面（よこ = ま中のじくからの きょり、たて = 高さ）を、たてのじくで ぐるっと回した形（つぼ・コップ・こま）。「回す角度」を 360 より小さくすると、ケーキのように切りとれます。
- **ロフト**: 「下の輪かく」から「上の輪かく」へ、じわっと形がかわる柱。「高さ」で長さを決めます。
- **スイープ**: 断面を、道（パス）にそって引っぱった形。道の点のはんけい = 断面の大きさの倍率です。
- **シェル（ちゅうぐう）**: どの形でも、右の「形」タブの「ちゅうぐう / シェル」を上げると中がくり抜かれ、かべの あつさ（mm）だけがのこります。0 でつまった形に戻ります。
## SVG を読み込む（絵を立体にする）

Illustrator や Inkscape などで作った SVG の絵を、ぐーっと押し出して立体にします。

1. 上の「ファイル」→「SVGを読み込む…」を押します。出てきたカードで「ファイルをえらぶ…」を押します（.svg ファイルを画面にドラッグしても開けます。ためしたい時は「サンプルの星を入れる」）。
2. カードに輪かくのプレビューが出ます。**大きさ**（長いほうの辺・初期値 60 mm）、**高さ**（初期値 10 mm）、**かどの丸み**、**上下を反転** を決めて「読みこむ」を押します。
3. ファイルの名前のグループができて、絵の中の かたまり 1 つずつが「押し出し」になります。ドーナツの穴のような**あなは、自動で「削る」形**になって、すぐ後ろに入ります。あとから 1 つずつ動かしたり、高さを変えたりできます。

- 読める図形: path（曲線・円弧もOK）、polygon、polyline、rect（角丸もOK）、circle、ellipse、`transform`、viewBox、mm・cm・in・pt などの単位。
- 読まないもの: 線（ストローク）だけの絵、文字、画像、グラデーション、`use`、`display:none` のもの。線だけの絵は「アウトライン化（塗りに変換）」してから読み込んでください。
- 角は 1 つの輪かくにつき 64 個までに自動で減らします（形はなるべく変えません）。2MB より大きいファイルや、形が 64 個をこえる時は、入るぶんだけ入れてお知らせします。
## メッシュを読み込む（STL・OBJ・3MF・PLY・GLB）

ほかのソフトで作った立体（メッシュ）を入れて、ふつうの形と同じように、動かす・回す・大きさを変える・ほかの形ととかす・「削る」で くり抜く・ほかの形を削る・ぬる・シェル・ならべる・書き出す ことができます。

1. 「ファイル」→「メッシュを読み込む…」（または F で「メッシュ」とさがす）を押してファイルをえらびます。ファイルを画面にドラッグしても開けます。
2. カードに ファイルの名前・種類・三角形の数・もとの大きさ と、データの注意（穴があいている、など）が出ます。**目標の大きさ**（いちばん長い辺・初期値はファイルの大きさ。ただし 200mm まで）、**向き**（自動・Y上・Z上。OBJ と GLB は自動で Y上）、**床に置く**、**まんなかに置く**、**細かさ**（64・96・128・160。1マスの数。目安の時間とファイルの大きさが出ます）を決めて「読みこむ」を押します。
3. 別のスレッドで はかります（進みぐあいの棒と「中止」）。できると、ファイルの名前の新しいグループに「メッシュ」の形が 1 つ入り、えらばれます。

- 中は「まわりの空間までの きょり」を 格子にしたデータ（ボリューム）です。1マス（いちばん長い辺 ÷ 細かさ）より細かい形は出ません。細かい角は、細かさを上げてください。
- 形の「丸み」は使えません（メッシュには角の情報がないため）。シェル（ちゅうぐう）・とけあい・削る・重ねる は使えます。
- 色は読みません（ざいしつで決めます）。形のコピー・ならべる・パターン・リンクコピーは、データを共有します（ふえません）。
- ほぞん: .meltcad の中に、小さくまとめて入ります（128 マスで 0.3〜1.3MB くらい）。同じメッシュを使う形は、データ 1 つぶんです。こわれたデータは、その形だけ取りのぞいてお知らせします。

## がしつ（かるさ）

上の右にある「がしつ」で、3D 画面の細かさを選べます。パソコンが重いときは「かるい」にしてください。

| えらびかた | 止まっているとき | 動かしているとき |
|---|---|---|
| じどう（はじめはこれ） | いちばんきれい | 画面の重さをはかって、なめらか（約100枚/秒）に動く細かさに自動でそろえる（4分の1〜いちばんきれい） |
| かるい | 半分の細かさ | 半分の細かさ |
| ふつう | 4分の3の細かさ | 4分の3の細かさ |
| きれい | いちばんきれい | ほぼいちばんきれい |

動かしているあいだは、影・ガラスのくっせつ・ぼんやりした光などをかんたんにして、軽くしています。手を止めると少しして（0.15 秒）きれいな絵にもどります。きれいな絵は、画面の上から数行ずつ数フレームに分けて描くので、止めた直後に画面が止まることはありません（「きれいに描画中」のあいだ、上から順にきれいになっていきます）。何も変わらないときは、絵をかきなおさないので、パソコンはほとんど動きません。

### 重いとき・おそいとき（速さをはかる）

- **F3**（または「がしつ」メニューの「フレーム時間を表示」）で、画面の左下に 1 秒あたりの枚数、CPU と GPU の時間（平均と最悪）、絵の細かさ（倍率）、形・グループ・コピーの数、使っているグラフィックスを出します。
- 「がしつ」メニューの **「速さをはかる…」** で、いくつかのシーン（パイプ・ライブラリのモデル 20 / 100 / 300 個・やわらかい材質）を 3 つの画面サイズで描いて、表にします（2〜3 分、測っているあいだは触らないでください）。結果は `meltcad-bench.txt`（MELTCAD の隣、書けなければ一時フォルダ）に保存され、窓の中でコピーできます。遅い、と感じたら、この表を送ってください。
- コマンドから: `meltcad --bench [出力ファイル.txt]`（`--quick` で小さく短く、`--frames N` で枚数）。窓は開かず、表を保存して結果を窓で見せます。

くわしくは PERF.md を見てください。

## もどす・保存・書き出し

- Ctrl+Z でもどし、Ctrl+Shift+Z か Ctrl+Y でやりなおします。マウスを離すと、そこまでが 1 回分です。200 回までもどせます。作品を開くと、もどす履歴は消えます。
- Ctrl+S: いま開いている作品に保存します。まだ名前がない時は、保存先と名前を聞かれます（初期名は「作品.yura」）。名前の後ろの * は、保存していない変更があるしるしです。
- Ctrl+O: 作品を開きます（.yura か .json）。ざいしつやライトの新しい項目がない古い作品も開けます。
- .yura は ふつうの JSON（文字だけのファイル）です。範囲をこえた数字は、読み込み時に安全な範囲に直されます。
- 書き出し（右上・ファイルメニュー）: **書き出し…** のカードで、ファイルの種類（STL・3MF・OBJ+MTL・PLY・GLB・文字のSTL）、**細かさ**（1マスの大きさ mm。0.05〜0.5 など。見つもりの三角形の数・時間が出ます）、単位（mm・cm・m・inch）と大きさ（%）、書き出す所（見えているもの・ぜんぶ・えらんだもの）、上の向き（Z / Y）、なめらかさ、三角形のへらしかた（平らな面をまとめる・数をきめる）、色を入れるか、ぬった色をむしするか をえらべます。3MF・OBJ・PLY・GLB には、場所ごとの色（GLBはつや・金属感も）が入ります。書き出しは別のスレッドで動き、進みぐあいの棒と「やめる」ボタンが出ます。カードの「プリントチェック」で、大きさ・体積・穴・0.8mmより薄い所・45°より はり出した面の割合を調べます。**画像 PNG** は見えているとおりを保存します。

## 上限

- 形: 512 個まで
- グループ: 96 個まで
- パターンのコピー・リンクコピー: ぜんぶで 256 こまで（形のワクは使いません）
- 形のアウトライン（押し出し・回転体・ロフト・スイープ）の点: ぜんぶで 65536 こ、線のふし: ぜんぶで 32768 こ
- ライト: 3 個まで
- ほぞんできるざいしつ: 24 個まで
- スケッチの角: 16 個まで（最低 3 個）
- SVG: 2MB まで。輪かく 1 つの角は 64 個まで
- メッシュ: 1つのシーンに、メッシュの形は 8 個まで。データは ぜんぶで 1600 万マスまで（128 マスなら 7 個ぶんくらい）。読むファイルは 256MB・三角形 500 万まで
- もどす: 200 回まで

## ライブラリ（できあいの形）

上の「ライブラリ」ボタンで、ひと・て・どうぶつ・どうぐ・くらしのもの・かぐ・たべもの・のりもの・たてもの・しぜん を開きます。小さな絵を押すと、いまのシーンのとなりに新しいグループとして入ります。上の「さがす」に名前（ひらがな・English）を入れると、全部の中からさがせます。入れたあとは、ふつうの形と同じく動かす・色を変える・とかす・削ることができます。

ライブラリの中身は `apps/meltcad/library/*.json` です（作り方は `library/README.md`）。

## コピー・貼りつけ・ならべる

- 「編集」メニュー、または Ctrl+C / X / V で、形やグループをコピー・切り取り・貼りつけできます。コピーは文字（JSON）としてクリップボードに入るので、別の窓や別のファイルにも貼れます。作品ファイル（.meltcad。古い .yura も開けます）の中身をそのまま貼ると、そのグループが全部入ります。
- 「編集 → ならべてコピー…」: えらんだ形（グループ）を、まっすぐ（X・Y・Z の間かく）またはぐるっと（Z軸のまわり、角度つき）にならべます。

## 書き出し・印刷

- 「書き出し」メニュー: 書き出し…（カード）、前の設定でもう一度（Ctrl+E）、画像(PNG)、プリントチェック。
- 「書き出し → プリントチェック」: 大きさ、体積、表面が閉じているか（穴がないか）を下の帯に出します。
- えらんでいる形の大きさ（幅 × 奥行 × 高さ）は、下の帯の右に出ます。
